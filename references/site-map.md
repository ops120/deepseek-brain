# DeepSeek 网页版交互地图（仅诊断 / 维护用）

> 正常流程一律走 `dsb` CLI，不要读本文件去手写 DOM 操作。
> 本文件只在 `SITE_CHANGED` 诊断或维护选择器时使用。
> 内容基于 2026-09 的实际界面截图与 v2 skill 的观察记录，M1 落地时需再复核一次。

## 页面结构（2026-09 截图核实）

- **模型**：**没有模型选择器**。页面横幅明示「快速、专家、识图模式已合并升级」——
  统一模型，同时具备日常对话、图片理解与复杂问题解决能力。不要寻找或假装能切换模型。
- **左侧栏**：顶部「**开启新对话**」按钮（⊕ 图标）；下方为会话历史，按「7 天内 / 30 天内」分组；
  另有搜索与收起侧栏图标。`--thread new` = 点「开启新对话」。
- **输入框**：欢迎页与对话页共用同一组件；多行 `textarea`（React 受控组件），
  占位符「给 DeepSeek 发送消息」。
- **工具栏**（输入框内）：**深度思考**胶囊、**智能搜索**胶囊（旧名「联网搜索」）、📎 回形针、
  蓝色圆形发送按钮。
  - 截图中「深度思考」是描边样式、「智能搜索」是蓝色填充——**颜色不等于开关状态**；
    真实状态用 DOM 属性或回答内证据（推理块 / 引用来源）判断，不靠颜色猜。
  - 两个开关都在**输入框工具栏**里，不在左上角下拉。
- **发送 / 停止**：生成中时发送按钮变为「停止生成」形态，流式结束后恢复。
- **答案容器**：聊天面板中最后一条助手消息；类名是哈希值（不可依赖），用结构 / 角色定位。
- **推理块**：开「深度思考」后的回答里出现的「深度思考」折叠区——用作 **深度思考生效的独立证据**。
- **引用**：开「智能搜索」后的回答底部来源列表。
- **线程 URL**：以本地存储为准（新建后用地址栏 / 历史捕获），不依赖抓取侧栏列表。

## 已验证的选择器（2026-09 真机实测，登录后）

| 用途 | 选择器 | 备注 |
| --- | --- | --- |
| 回答正文 | `[class*="ds-assistant-message-main-content"]` | 稳定语义类名，取最后一个 |
| 推理块 | `[class*="ds-think-content"]` | 用「发送前后数量差」判断**本次**是否真的开了深度思考，避免把历史消息的推理块算进来 |
| 引用角标 | `[class*="ds-markdown-cite"]` | 内联在正文里：`<a href="源"><span class="ds-markdown-cite">[3]</span></a>` |
| 来源统计 | 文本 `搜索到 N 个网页` | 来源卡片只有站点图标、无可读标题 → 引用标题取域名 |
| 消息容器 | `[class*="ds-message"]` | 取最后一个 |
| 输入框 | `textarea[placeholder*="给 DeepSeek"]` | 占位符末尾**带一个空格**：「给 DeepSeek 发送消息 」 |
| 发送键 | `.ds-button--circle` | 输入框为空时带 `ds-button--disabled` |
| 开关按钮 | `.ds-toggle-button`（图标 `ds-toggle-button__icon`） | 状态从 `aria-*` / 类名读出 |

**抽取要点**：正文必须**跳过引用角标**再取文本，否则会得到 `代号 Krypton-\n3\n-\n4` 这种被角标切碎的结果。

## 已知实现细节

- **输入注入**：直接设 `textarea.value` 会被 React 冲掉。正确做法是原生 setter + `input` 事件：
  `Object.getOwnPropertyDescriptor(HTMLTextAreaElement.prototype, "value").set.call(ta, text)`，
  然后 `ta.dispatchEvent(new Event("input", { bubbles: true }))`。
- **引用失效**：流式渲染后旧 DOM 引用会失效；不要缓存节点引用。
- **超长输入**：> 50 KB 分片写入，每片间隔 sleep，避免 React debouncer 丢帧。
- **上传**：直接对隐藏 `<input type="file">` 调 `setInputFiles`，比点击 📎 再走原生对话框可靠。
- **线程 URL**：新建对话后地址栏 / 历史中出现 `chat.deepseek.com/a/chat/s/<id>`。

## 常见失败形态

- 登录墙：页面出现 登录 / Log in 按钮或二维码。
- Cloudflare：`Checking your browser...` / 人机验证图。
- 限流：出现「请求过于频繁」类提示。
- 流式停滞：「停止生成」控件长时间不消失，或文本长时间不再增长。

## 维护规则

- 选择器集中在 `scripts/dsb/src/site/selectors.ts`，每项形如 `{ primary, fallbacks[], verify }`。
- 改完跑 `doctor --deep` 与夹具测试；不要把选择器散落到其它地方。
